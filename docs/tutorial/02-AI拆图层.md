# 2. AI 拆图层

Live2D 要的是分层的图：头发、脸、眼睛、嘴、衣服、手臂……各在各的图层上，被挡住的地方也要画出来，动起来才不会露洞。这一步用 [See-through](https://github.com/shitagaki-lab/see-through)：它把一张立绘拆成二十几层，还会把被挡住的部分「猜」着补出来。

有两种做法：

- **在网页上拆**：不用装软件，也不挑显卡，适合先试试。每天能拆的次数有限。
- **在自己电脑上拆**：用 ComfyUI，要一块好显卡。次数不限，还能用本项目的脚本一条命令跑完。

两种拆出来的 PSD 图层名一样（`front hair`、`eyewhite-l` 这些），后面的步骤相同。

## 在网页上拆

See-through 的作者放了两个在线版，用的是同一个模型：

| 在线版 | 说明 |
| --- | --- |
| [Hugging Face](https://huggingface.co/spaces/24yearsold/see-through-demo) | 英文界面。免费，但用的是共享显卡，每天的用量有限：官方说登录 Hugging Face 账号后大约一天能拆一两张，不登录更少。用量从第一次用起，24 小时后恢复 |
| [魔搭 ModelScope](https://modelscope.cn/studios/ljsabc/See-Through) | 中文界面，不用登录，写这篇时免费。Hugging Face 打不开时用它 |

在线版要把立绘上传到 Hugging Face 或魔搭的服务器上处理。不想把图传出去，就在自己电脑上拆。

步骤（括号里是 Hugging Face 版上的英文）：

1. 上传立绘。不是正方形的会自动补边。
2. 选「分辨率」（Resolution）：拆出来的 PSD 就是这个边长的正方形。魔搭版默认 1024。Hugging Face 版默认 768，官方建议免费用量就用 768，调高了容易超时，也更快用完当天的用量。
3. 勾上「左右拆分手臂、眼睛与耳朵」（Split arms, eyes and ears into left/right layers）：手臂、眼睛、耳朵各拆成左右两层，和苏墨的 PSD 一样。腿不拆；左右两边连在一起的部件也拆不开。
4. 「随机种子」（Seed）先不动。结果不满意，换个数再跑一次。
5. 点「开始运行」（Run），等几分钟（官方说 1280 的分辨率要 2～3 分钟），然后下载分层 PSD。

拿到 PSD 以后，跳到下面的「[拆出来的东西要怎么看](#拆出来的东西要怎么看)」。

## 在自己电脑上拆

### 装好 ComfyUI 和插件

1. 装 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)，能打开网页界面就行。默认地址是 `http://127.0.0.1:8188`。
2. 把 [ComfyUI-See-through](https://github.com/jtydhr88/ComfyUI-See-through) 装进 `ComfyUI/custom_nodes/`，用插件管理器装或者 `git clone` 都行，再照插件的说明装好依赖。
3. 重启 ComfyUI。

See-through 的模型约 13 GB，第一次跑时会自动从 Hugging Face 下载。下载慢的话，可以照插件说明手动下载，放进 `ComfyUI/models/`，再在下面的命令前加 `$env:SEETHROUGH_NO_DOWNLOAD = "1"`。

拆图层很吃显存。跑之前先关掉别的占显存的程序：本地大模型、语音合成、游戏之类。

### 一条命令拆完

ComfyUI 开着的时候，在本项目目录里运行：

```powershell
node pipeline/seethrough_run.mjs <立绘.png> <输出目录>
```

比如：

```powershell
node pipeline/seethrough_run.mjs D:\art\sumo_chibi_1280.png D:\art\split_v1
```

它会：

1. 把立绘上传给 ComfyUI；
2. 按「拆层 → 估深度 → 整理 → 存 PSD」跑一遍 See-through，一般要几分钟，看显卡；
3. 把结果从 ComfyUI 的输出目录挪到你给的输出目录：一份分层 PSD，每一层一张 PNG，外加一份图层信息的 JSON。

可选的环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `COMFY_URL` | `http://127.0.0.1:8188` | ComfyUI 的地址 |
| `COMFY_OUTPUT_DIR` | 自动判断 | ComfyUI 的输出目录。脚本会从 ComfyUI 的启动参数里找，找不到就要你自己写 |
| `SEETHROUGH_NO_DOWNLOAD` | 不设 | 设成 `1`：不自动下载模型 |

命令后面还可以跟两个数：分辨率（默认 1280）和随机种子（默认 42）。结果不满意，换个种子再跑一次。

## 拆出来的东西要怎么看

用 Photoshop、Krita 或网页版的 [Photopea](https://www.photopea.com/)（见下一章）打开拆出来的 PSD，一层一层看。要知道 See-through 的脾气：

- **它是把每一层「重画」了一遍**，不是从原图上剪下来的。看得见的地方颜色、细节会和原图有出入，比如花纹变了、线条变粗。
- 被挡住的地方（脸后面的头发、袖子里的手臂）是它猜着补的，可能不太对。
- 它只认识常见的部件。苏墨的尾巴就被当成头发，画进了后发里，还画成了一缕缕发丝，没有鳞片。
- 一件连身的衣服（比如旗袍）会是一整层，前片、后摆不会自动分开。

所以拆完一般还要整理一遍：

1. **看得见的地方换回原图的颜色**：拿原图盖在上面，只留被挡住的那部分用 See-through 补的。
2. **切出认错的部件**：比如把尾巴从后发里切出来，单独一层。
3. **一件衣服按前后分开**：前片一层，腿后面的里衬 / 后摆一层，这样腿能在中间。

可以全在绘图软件里手动做。苏墨用的是两个脚本，在 `pipeline/` 里：

- `build_layers.py`：做上面那三件事。尾巴轮廓是手描的坐标，旗袍是按 See-through 给的深度图逐像素分前后的，**都是专门为苏墨写的**。换你的角色要改脚本里的坐标和部件名，用法写在脚本开头。
- `make_psd.py`：把整理好的各层 PNG 按顺序打包成 PSD，顺手去掉 See-through 在画布四角留下的半透明碎点。

苏墨第一版整理完，合成出来和原图的平均差异是 0.5%，肉眼看不出来。
