# 9. 常见问题

## 装和启动

**桌宠只显示一个气泡，没有角色。**

气泡上写着缺什么，常见的有：

- 「还没装 Live2D 运行库」：运行 `npm run setup`，见[首页](../../README.md#快速开始)。
- 「模型文件不在」：档案里 `model` 的路径不对。相对路径按档案所在的目录算，随程序带的档案按项目目录算。
- 「模型载入失败」：模型文件坏了，或者不是 Cubism 3 以上的模型（`.model3.json`）。

**`npm install` 很久没动静，或者第一次 `npm start` 卡在下载。**

Electron 本体要从国外下载。在同一个 PowerShell 窗口里设镜像再跑：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
npm install --registry=https://registry.npmmirror.com
npm start
```

**`npm run setup` 说解压失败。**

先手动把 SDK 的 zip 解压，再把解压出来的目录传给它：

```powershell
npm run setup -- "D:\下载\CubismSdkForWeb-5-r.5"
```

**双击图标打开了两只？**

不会。第二次启动会把已经开着的那只亮出来，然后自己退出。

## 点和拖

**点角色没反应。**

- 看看是不是开了「不影响鼠标」：开着时整个桌宠都不挡鼠标。去托盘图标的菜单里关掉。
- 偶尔系统不把「按下」送进桌宠窗口（息屏唤醒后出现过）。桌宠有一个后台的拖动助手兜底，松手时会补一次点击。

**透明的地方挡住了后面的窗口。**

命中区域按角色画出来的像素算，边上留了大约 8 像素的余量，方便点中。余量之外的透明处应该点得穿。还是挡的话，看看模型里有没有几乎透明、但没完全透明的大块（比如 See-through 留下的碎点），回 PSD 里擦掉。

**拖到屏幕边贴不住。**

贴边按角色轮廓算。头发、尾巴伸得很远的角色，轮廓就宽。

## 生成模型

**存了 PSD，没反应。**

- 「系统」页的模型卡片上是不是写着缺什么工具；
- 档案里有没有写 `psd`，路径对不对；
- 有的软件是「先存临时文件再改名」的，桌宠每 3 秒也会自己检查一遍，稍等一下。

**闭眼、嘴没认出来，模型里眼睛不会闭。**

看图层名，表在[第 3 章](03-修图层.md)。闭眼叫 `eye close`，不叫「闭眼线」；中文名在有的保存方式下会变乱码，换成英文名最稳。

**画面上拉出几根细线连到四角。**

某一层（多半是头发）网格生成失败，退化成了整张画布。可以试试：

- 换新版的官方 PSD2Live；
- 换我们改过的版本；
- 把那层的碎发丝合并、擦掉零碎的小点。

**闭嘴的地方出现两条线。**

同时有张开的嘴（`mouth`）被压成的缝，和你画的 `mouth close`。在档案的 `psdSkipLayers` 里写上不要的那层。

**生成成功，但转头时露出一块透明的洞，或者一条直的切口。**

那是被挡住的地方没补完整，回[第 3 章](03-修图层.md)补画。苏墨踩过的两处：

- 后发里留着一圈下巴的旧线；
- 尾巴根部，后发被切出了一道直边。

## 拆图层

**See-through 把尾巴画成了头发。**

它不认识尾巴，会把尾巴当成后发。从后发里切出来，单独一层叫 `tail`，见[第 2 章](02-AI拆图层.md)。

**拆出来的颜色和原图不一样。**

See-through 是重画，不是剪切。看得见的地方用原图的颜色替换回来。

**显存不够。**

关掉别的占显存的程序再跑；还不够的话，把分辨率参数调小（比如 1024）。

## 其他

**设置、日志在哪？**

`%APPDATA%\inkpet\`，控制中心「系统」页能打开。出了问题看那里的 `main.log`、`renderer.log`。

**可以拿来做直播 / 商用吗？**

- 程序代码按 MIT，可以。
- 苏墨的美术不行（CC BY-NC 4.0），换成你自己的角色。
- Live2D 的部分要看 Live2D 的许可，见 [THIRD_PARTY.md](../../THIRD_PARTY.md)。
