# 0. 开始之前

## 整条流程

```
立绘（一张 PNG）
  │  第 2 章：ComfyUI + See-through 自动拆成分层
  ▼
分层 PSD
  │  第 3 章：在 Photoshop / Krita 里补画、改名字
  ▼
整理好的 PSD
  │  第 4 章：PSD2Live 生成
  ▼
Live2D 模型（model3.json + moc3 + 贴图 + 物理）
  │  第 5 章：写一份角色档案
  ▼
桌面上的桌宠 ──（第 6 章）── 改 PSD、存盘，几秒后自动换成新模型
```

## 要装的软件

| 软件 | 用在哪一章 | 说明 |
| --- | --- | --- |
| InkPet（本项目） | 5～8 | 照[首页的快速开始](../../README.md#快速开始)装好，能看到苏墨就行 |
| [ComfyUI](https://github.com/comfyanonymous/ComfyUI) | 2 | 跑 AI 拆图层。国内常用整合包（比如秋叶整合包）也行 |
| [ComfyUI-See-through](https://github.com/jtydhr88/ComfyUI-See-through) 插件 | 2 | 装进 ComfyUI 的 `custom_nodes`；模型第一次用时自动下载，约 13 GB |
| Photoshop 或 [Krita](https://krita.org/)（免费） | 3、6 | 修图层。别的软件也行，只要能读写带图层的 PSD |
| Python 3.10 或更新 | 2、4、6 | 再装几个包：`pip install psd-tools numpy pillow scipy` |
| [PSD2Live](https://github.com/tsunehimatoi/psd2live/releases) | 4、6 | PSD → Live2D 模型。官方免安装包解压就能用，自带 Java；想要尾巴会摆，换我们改过的版本（要 Java 21），见第 4 章 |

## 电脑配置

- Windows 10 / 11，64 位。
- 显卡：拆图层（第 2 章）要一块显存 8 GB 以上的 NVIDIA 显卡，16 GB 比较从容。其余步骤不挑显卡。
- 硬盘：See-through 的模型约 13 GB，ComfyUI 本身再加几个 GB。

没有合适的显卡也能做：第 2 章换成在绘图软件里手动分层（就是画师平时给 Live2D 拆图的做法），后面几章完全一样。

## 每一步留下的文件

建议每一步都另存一份，别覆盖上一步的。做苏墨时是这样放的（仓库里只留了最后那份 PSD 和模型）：

```
assets/sumo/src/
  sumo_chibi.png        第 1 章：选中的立绘
  sumo_v1.psd           第 2 章：拆出来、拼好的第一版
  sumo_v2.psd …         第 3 章：每次大改另存一份
  sumo.psd              之后一直在改的这份（桌宠盯着它）
assets/live2d/sumo/
  sumo.model3.json …    第 4、6 章：生成的模型
```
