# 语音

桌宠可以把台词念出来，念的时候按音量对口型。设置都在控制中心的「语音」页。

## 合成服务

语音默认关闭，合成服务列表默认为空。先配置千问或自定义接口，勾选要用的服务，再开启语音。「语音」页上可以选几个合成服务，并排好先后。念的时候只按选定的顺序试，第一个出声的算数。已经开始出声的，就算中途断了也不换下一个，免得前半句念两遍。

### 阿里云百炼 · 千问语音合成

- 音质好，开口快（约 0.3～1 秒）。按字数计费，价格以阿里云的页面为准。
- 要自己的 API Key：开通阿里云百炼，在控制台创建 API Key，粘贴到「语音」页保存。
- 音色可以选自带的芊悦（Cherry）、苏瑶（Serena）、千雪（Chelsie）、晨煦（Ethan），也可以直接填阿里云文档里别的音色名。
- 地域：国内账号选「北京」，国际站的 Key 选「新加坡」。
- 用的模型是 `qwen3-tts-flash-realtime`，经 WebSocket 连接。
- 密钥用 Windows 的数据保护（Electron 的 safeStorage）加密后存进 `config.json`，只发给阿里云。
- 实测：一个账号同时最多开 3 条合成连接，桌宠一次只用一条。偶尔连上后迟迟不出声，桌宠会在 1.5 秒后换一条连接重试，最多 3 次。

### 自定义接口

用来接你自己的语音服务，比如本机的 IndexTTS、GPT-SoVITS，或者别的云服务。照下面的协议写一层薄薄的转接就行，然后在「语音」页填上地址和语言代码（默认 `ZH`）。

Windows 自带语音仅保留为手动选择的兼容选项，音质较差，不推荐使用。程序不会自动启用、枚举系统语音或把它加入失败兜底；只有主动勾选该服务或点击其「刷新」按钮时才枚举。未选择它时不会调用 System.Speech。

## 自定义接口的协议

请求：

```
POST http://127.0.0.1:9882/tts/stream        （地址自己定）
Content-Type: application/json; charset=utf-8

{"text": "要念的字", "lang": "ZH"}
```

- `text`：要念的字。桌宠已经去掉了 Markdown 记号、代码、网址、文件路径、表情和括号里的动作描写，最多 400 字。
- `lang`：「语音」页上填的语言代码，原样转给你。

回复：状态码 200，正文是 **一行一个 JSON**（NDJSON），边合成边写：

```
{"type":"chunk","seq":1,"sampleRate":24000,"pcm":"<base64>"}
{"type":"chunk","seq":2,"sampleRate":24000,"pcm":"<base64>"}
{"type":"done"}
```

- `chunk`：一段音频。
  - `pcm` 是 **16 位有符号、小端、单声道** 的 PCM，用 base64 编码。
  - `sampleRate` 是采样率，不写算 24000。
  - 每段多长都行。第一段越早写出来，桌宠开口越快；建议每段 0.5 秒左右。
- `done`：念完了。
- `{"type":"error","error":"原因"}`：出错了。原因会显示在「语音」页上，桌宠接着试下一个合成服务（如果还没出过声）。
- 别的 `type` 和解析不了的行会被忽略。
- 状态码不是 200 时算出错，正文的前 160 个字会显示出来。
- 60 秒没有动静算超时。用的人按了「停下」时，桌宠会直接断开连接。

一个能直接跑的例子见 [examples/beep-tts.mjs](examples/beep-tts.mjs)。它不真的合成语音，只按字数回一串「嘀」声，用来试通协议：

```powershell
node docs/examples/beep-tts.mjs
```

然后在「语音」页把自定义接口的地址填成 `http://127.0.0.1:9882/tts/stream`，排到第一个，点「试听一句」。

## 念什么、什么时候念

| 什么时候 | 念什么 | 开关 |
| --- | --- | --- |
| 点角色时 | 角色档案 `lines.say` 里随机一句（没有就用 `lines.stats`） | 「语音」页「点角色时念」 |
| 没人碰它时 | 同上 | 「语音」页「空闲时说一句」（隔几分钟，0 = 不说）；电脑 5 分钟没人操作（包括息屏）时不说 |
| 右键菜单「说一句」 | 同上 | |
| 别的程序叫它说 | 推来的话 | [本机接口](local-api.md) `POST /say` |

- 正在念的时候又来新的，就排在后面，最多排 3 句，再多的丢掉。
- `Ctrl+Alt+U`、右键菜单「停下」、本机接口 `POST /stop`，都会停下正在念的并清空排队的。
- 「语音」总开关关着时，台词照样显示在气泡里，只是不出声。
